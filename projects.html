Projects

  • LLM Pricing Agents in Dynamic Markets
    Research codebase for the pricing study: a calibrated logit market, structured model clients with persistent private notes, a regulator implementing passive, revision and veto oversight, and the round loop that ties them together. The repository publishes the full run records, the provenance of every figure, and the ambiguities found in the protocol it replicates.
    Code | Research
  • Long-Tail Driving Scene Discovery
    Rare, safety-critical driving scenes are hard to find because they are not statistical outliers - a wheelchair user at a crossing looks like an ordinary street scene. This project searches the hidden states of a frozen vision-language model instead of the images: a sparse autoencoder trained with a tail-guided objective splits the representation into a normal and a long-tail subspace, and the units that fire give a readable reason for every flagged frame. Several units correspond to nameable conditions and can be used as retrieval keys over unlabelled data.
    Code
  • CNN-Mamba Forest Type Segmentation
    Pixel-level forest type mapping from Sentinel-2 time series, climate variables and elevation, evaluated on the ForTy v1 benchmark. A Mamba-2 selective state-space block handles the temporal axis, a structure-aware fusion layer mixes each patch with its neighbours in the bottleneck, and a dynamic fusion module weights the three modalities per sample. Includes a command-line tool that applies a trained checkpoint to new tiles.
